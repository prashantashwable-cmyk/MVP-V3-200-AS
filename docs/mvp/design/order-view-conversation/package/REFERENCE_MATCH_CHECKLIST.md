# Reference Match Checklist

Use only the original approved image, not a substitute.

## Image and viewport
- [ ] Original reference copied to `reference/original-reference.png`
- [ ] Image dimensions and aspect ratio recorded
- [ ] Target device/viewport size recorded
- [ ] Device safe areas and browser/app chrome accounted for

## Geometry
- [ ] Overall frame/content bounds
- [ ] Header height and internal padding
- [ ] Main content width and left/right margins
- [ ] Column widths and gutters
- [ ] Card/message/task dimensions
- [ ] Vertical spacing between sections
- [ ] Border radius, stroke, shadows and separators
- [ ] Bottom navigation position and safe-area inset
- [ ] Sticky vs scrolling regions

## Typography
- [ ] Font family compared with repository-loaded fonts
- [ ] Size, weight, line height, letter spacing
- [ ] Text wrapping and truncation
- [ ] Timestamp and metadata styles
- [ ] Heading/body/label hierarchy

## Visual details
- [ ] Colors sampled from reference
- [ ] Gold accent use and emphasis
- [ ] Icon family, size, stroke and baseline
- [ ] Image assets and crop/fit behavior
- [ ] Status badges and role labels
- [ ] Loading, empty, error, disabled and permission states

## Interaction and responsive behavior
- [ ] Touch targets usable on mobile
- [ ] Keyboard focus and activation work
- [ ] No horizontal overflow at target width
- [ ] Conversation chronology remains readable
- [ ] Breakpoint behavior checked at narrow and wide viewports
- [ ] Actions reflect true workflow state, not optimistic fake state

## Comparison report
Record viewport, screenshot file names, differences, and whether each difference is visual, data-driven, or platform/font-related. Do not claim pixel-perfect without a measured comparison.
