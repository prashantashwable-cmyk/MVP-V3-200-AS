## Classification categories (per this phase's own required list)

- **harmless_representation** — the two stores agree once you look at the right field; any
  surface difference is presentational only (e.g. one store storing a derived boolean, the
  other storing the source fields it is derived from).
- **expected_migration_difference** — a real, DOCUMENTED, intentional difference from the
  bridge's own known vocabulary translation (e.g. legacy PO status strings like `"Sent"`
  mapping to canonical `"sent_to_supplier"`) or an entity that exists canonically with no
  1:1 legacy counterpart by design.
- **repairable_discrepancy** — a real gap that is fixable without a live credential (e.g. a
  missing audit event) but was not found necessary to fix this run (found present).
- **critical_divergence** — a real, unexplained financial/identity/ownership mismatch. NONE
  were found this phase (see summary below) — this category exists precisely so a real one,
  if ever found, is never silently smoothed over into a softer label.
